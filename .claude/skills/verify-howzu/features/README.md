# 好租功能地图

每个文件是一个用户功能，写给下一个接手的 AI：从用户角度怎么进、怎么操作、看到什么才算成功。脚本 `tools/verify/howzu-verify.js` 里的流程名和这里的文件名一一对应。

| 流程 | 文件 | 一句话 |
|---|---|---|
| `listings` | [listings.md](listings.md) | 每套在租房源的周租在首页、列表、房源页三处一样 |
| `book` | [book.md](book.md) | 房源页预约看房，短信带房源编号和时间，≤ 4 次点击 |
| `landlord` | [landlord.md](landlord.md) | 查租金页房东卡片估租金，一键带到发房源页，≤ 3 次点击 |
| `owner` | [owner.md](owner.md) | 房东卡片“想找人托管”留资，来源记“租金查询-房东” |
| `tenant` | [tenant.md](tenant.md) | 租房列表底部留求租需求 |
| `callback` | [callback.md](callback.md) | 全站右下角“联系我们”留电话等回电 |
| `post` | [post.md](post.md) | 免费发房源：照片、粘贴自动填、预览、确认发布 |
| `english` | [english.md](english.md) | ?lang=en 切英文并记住 |
| `pages` | [pages.md](pages.md) | 主要页面在 390、360 宽没有报错、没有横向溢出 |

还没进地图（以后加）：收藏和对比、地图看房和按学区看、查学区、投资测算、汇率比价、后台 admin.html（要登录）、贴帖入库和房东确认页 confirm.html。
