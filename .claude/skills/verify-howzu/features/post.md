# 免费发房源

房东不用注册：传照片 → 粘贴介绍自动填 → 补齐基本情况 → 留联系方式 → 发布 → 预览 → 确认发布。提交后待审核，不直接上线。

## Sub-features

- 照片压缩（最多 15 张）
- 粘贴介绍自动识别周租、房型、家具、入住时间等
- 缺项提示，点“发布”自动跳到第一个没填的地方
- 预览卡片，再改改或确认发布
- 自动生成中英文标题和介绍（没写时用免费模板）

## How to get to it (user POV)

1. 任意页面点“＋ 免费发房源”。
2. 传照片，粘贴一段介绍。
3. 填地址和微信或手机，勾选“我确认……符合维州最低租住标准”（必勾，维州 s65B）。
4. 点“发布”，看预览，点“确认发布”。

## Driving it with howzu-verify

`node tools/verify/howzu-verify.js run post`

- 传 photos/ 里第一张原图，粘贴“CBD 两房一卫，周租 $720，带家具包网，马上入住，租期一年”。
- 检查：出现“已帮你填好”，周租框 = 720；没勾最低标准确认时点发布不出预览、提示“勾选确认”；勾上后预览出现；提交的 highlights 含“房东已确认符合最低租住标准”；确认后照片上传请求 ≥ 1，提交内容周租 720、地址含 Spencer、微信 verify_test，没有直接设为上线。

## Gotchas

- 页面脚本从 esm.sh 加载 Supabase 库；连不上时整个表单不工作，而且页面不提示。运行环境连不上时本流程记为“没验证”。
- 草稿存在浏览器本地；每次用新的浏览器环境，避免旧草稿干扰。
