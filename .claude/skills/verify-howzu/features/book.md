# 预约看房

租客在房源页点“📅 预约看房”，选日期和时间，点“发送预约”。手机上直接打开短信，内容带房源编号和时间；电脑上复制内容。

## Sub-features

- 房源页底部按钮跳到 rentals.html?id=<id>#book，自动打开“预约看房”弹窗
- 日期按钮（7 天，或只有周末，或固定开放时间）
- 时间按钮
- 发送预约（手机：打开短信；电脑：复制）
- 加到日历（.ics）

## How to get to it (user POV)

1. 房源页底部点“📅 预约看房”。
2. 弹窗里点一个日期、一个时间。
3. 点“发送预约”。

## Driving it with howzu-verify

`node tools/verify/howzu-verify.js run book`

- 手机模式（触屏），第一套在租房源。
- 选第一个周六或周日、下午 2 点。
- 证据：打开的短信链接（打开的短信.txt），必须含“房源编号 <id>”和“下午 2 点”。
- 点击次数 ≤ 4。

## Gotchas

- 电脑模式（鼠标）走“复制”分支，不打开短信；脚本用手机模式。
- 房源写了“视频看房”时，短信里会带“视频看房”。
